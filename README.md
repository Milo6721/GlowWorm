# GLOWORM — Reef Defense

Co-opowa gra 3D w stylu bloków (Three.js) dla 1–4 graczy. Bronicie Serca Rafy przed falami stworów z głębin.

- Multiplayer przez Supabase Realtime Broadcast (kanały `gloworm_room_XXXX`, bez tabel w bazie)
- Klasy: Strzelec, Snajper, Rozpylacz, Mag
- Ulepszenia po każdej fali, bossy co 5. falę, bonusy, elity, modyfikatory fal
- Sterowanie: WASD + mysz (Spacja = puls, Shift = zryw), na telefonie wirtualny drążek i auto-celowanie

Wystarczy jeden plik `index.html` — wrzuć go na dowolny hosting statyczny (np. Vercel).
